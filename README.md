# 🎵 HTML Rhythm Game | HTML 趣味节奏器

> **Browser-based rhythm game built with pure HTML/CSS/JavaScript. Hit the notes in time with the music, keyboard controls, score tracking, and combo system. No dependencies, runs in any browser.**
>
> 纯 HTML/CSS/JavaScript 构建的浏览器节奏游戏。跟随音乐击打音符，键盘控制，分数追踪和连击系统。无依赖，任何浏览器均可运行。

---

## 🌟 Features | 核心特性

- **Pure HTML/JS** — No frameworks, no dependencies
- **Keyboard Controls** — Arrow keys / D-F-J-K for notes
- **Score System** — Points, accuracy, combo multiplier
- **Multiple Difficulties** — Easy / Normal / Hard
- **Visual Effects** — Note animations, hit feedback
- **Audio Sync** — Notes synchronized with music

---

## 🚀 Quick Start | 快速开始

```bash
# Just open in browser
open index.html
# or double-click index.html
```

---

## 🎮 Controls | 操作

| Key | Action |
|-----|--------|
| **D / F / J / K** | Hit notes (4 lanes) |
| **↑ ↓ ← →** | Alternative controls |
| **Space** | Pause / Resume |
| **R** | Restart |
